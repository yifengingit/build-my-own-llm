# Build My Own LLM

在 MacBook 上亲手实现并从零训练一个小型语言模型，通过项目学习 LLM 工程。

第一版以英文文本为主，使用 PyTorch 基础能力，自己实现 Transformer 关键模块与训练循环，从随机初始化开始，交付模型权重、评估记录及文本生成入口。
